# v0.3.0 — 视觉与内容双升级

本版本不新增功能阶段（S1–S5 流水线保持不变），但把 **UI 呈现 + 知识准确性** 推到了新的水平。研究员打开报告的第一印象，从"还算像样的技术报告"升级到"像仪器，也像一本书"。

---

## ✨ 重点变化

### 1. Plutchik 情绪盘对齐权威框架 + 中英双语

- **数据源换成 Six Seconds（6seconds.org）Eight Core Emotions 官方版本**。之前的"相似词 / 典型感受 / 在告诉你 / 如何帮助你"四字段来自我早期的拼凑，已全部替换为 6seconds 的规范文本。
- **每条释义都是中英双语对照**：中文（衬线粗体 15px）主显、英文（衬线斜体 13px 灰色）辅显。标签、标题、解释、对立对全部双语。
- 术语修正：`surprise` 的中文从"惊讶"改为学术标准的"**惊奇**"。

### 2. 真·ECG 心电图质感

在情绪曲线图的 canvas 上叠加了两层装饰：

- **方格纸底纹**：12px 小格 + 60px 大格的橙色 grid，边缘淡出遮罩，像临床监护仪的底板。
- **扫描光柱**：一条 1px 橙色游标 + 22% 宽的余辉拖尾，9 秒一轮从左扫到右，类似示波器。尊重 `prefers-reduced-motion`。

### 3. 章节升级为仪器面板（Signal Channels）

每个 `<section>` 从"编辑部样式的文字块"变成"带框的监测通道"：

- **Dual-border 框架**：外框 1px + 内侧 1px 高光 hairline，像金属铭牌。
- **4px 橙色左轨**：24px halo 外发光，hover 时升到 36px。
- **顶部 bezel 光**：1px 橙色线从左上角向右渐隐，模拟屏幕反光。
- **细噪点表面**：3px 网格的 CSS radial-gradient 点阵，提供材质感。
- **脉动活体指示**：标题栏右端 2.4s 一次的橙色脉冲，对应 ECG 主题。

### 4. 全局大气背景

报告页面不再是 photoshop 纯黑：

- 4 层 `fixed` radial-gradient 叠加：左上角暖橙泄光、顶中冷白反光、右下橙色回光、3px 白色细噪点。
- 所有峰值强度 < 7%，整体仍是近黑，但"像在灯下拍的"而不是"死屏幕"。

## 🐛 缺陷修复

- **§04 栏宽随筛选漂移**：切换「惊奇」/「期待」等筛选时，左右两列宽度不一致。根因是 Grid `1fr` 遇到超长不可断内容（如 TP02 的 `9999...9` 复读）会撑破轨道。修复为 `minmax(0, 1fr)` + 强制 `word-break` on 证据行和弹幕行。
- **情绪盘点击态视觉反馈**：花瓣选中后，右侧面板 `SELECTED` 徽章颜色和花瓣颜色不同步。已修复。

## 🗑 清理

- 移除 5 处章节标号里的 `§` 装饰符（`§ 01` → `01`），以及 TL;DR 段首的 `§` 字符，改用 4px 橙色光晕竖条。
- 移除各章节右上角 `aside` 的文字（`bilibili source` / `Lead I + Lead II` / `9 turnpoints · 1886 danmakus` / `Plutchik 8-dim`），只保留一颗脉动点作为统一的"活体指示"。
