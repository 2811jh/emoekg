# emoekg v0.5.0 — §02 多 variant + 心电图 PULSE 心跳

**Release date:** 2026-05-20

§02「影像与心电」模块大改：4 种视觉风格切换、情绪带状图、关键时刻卡墙、时间帧轴移动到 §04，以及 D 综合版心电图 PULSE 心跳呼吸。此版本确保新生成的 HTML 报告可复现当前交付版的视觉效果。

## Added

- §02 右上角浮动风格切换器：A 编辑版 / B 仪表盘 / C 数据墙 / D 综合版。
- `Emotion Tape` 情绪带状图：8 维 × chunk 的时间带视图。
- `Key Moments` 关键时刻卡墙：展示 turnpoints 高光卡，点击可跳转视频。
- D 综合版：`八维情绪心电` + `情绪带状图 & 关键时刻` 的新叙事顺序。
- D 综合版 ECG：走纸推进 + PULSE 心跳呼吸 + HUD 角标 + 顶部样本/峰值/时长 readout。
- §04 开头新增时间帧轴，点击三角跳转对应转折点。

## Changed

- §02 文案中文化：英文仅作为次级标注（如 Lead II / joy）。
- §02 顺序调整为：实时画面 → 八维情绪心电 → 情绪带状图 & 关键时刻 → 关键读数。
- D 模式 ECG 高度调整为 320px，比 C 模式略高。
- ECharts D 模式关闭 splitLine，避免与心电图纸背景重叠。
- ECG 折线发光从 CSS filter 改为 ECharts lineStyle shadow，不再影响图例。
- turnpoint markPoint 统一为三角形，valley 用向下三角。

## Fixed

- 修复 D 模式 ECG 两套网格叠加造成的静止背景线问题。
- 修复图例跟随整张 chart 发光的问题。
- 修复样本/峰值/时长 readout 与 dataZoom 坐标轴重叠的问题。
- 修复 §02 模块在 D 模式下用 float 造成布局塌陷的问题，改为 grid wrapper。

## Version

- package version: `0.5.0`
